Convolutional Neural Networks

A CNN slides a small filter over a picture to find patterns such as edges.

Image 6×6
⊛
Filter 3×3
=
Output 4×4

Each output = multiply and add the 9 pixels under the filter.

Conv: find patterns➜ReLU: keep positives➜Pooling: shrink, keep strongest➜Dense: decide the label
Big numbers in the output mark where the pattern (here, a vertical edge) was found.

Working with Text and Sequences

An RNN reads one word at a time and keeps a memory (h) of what it has read.

Bar height = memory value h.

Rule: new memory = f(old memory, current word). The same cell is reused at every step, which is why it handles any sentence length.

TensorBoard Visualization

Training means rolling a ball down a loss hill. TensorBoard draws the loss curve on the right.

Learning rate 0.20

Learning rate is the step size. Too small is slow, too big overshoots. Run tensorboard --logdir logs to see curves like this for real.
