1. Bit vs Qubit and Dirac Notation

Notes

  • A qubit state is |ψ⟩ = α|0⟩ + β|1⟩, where α and β are complex numbers called amplitudes.
  • A ket |ψ⟩ is a column vector. A bra ⟨ψ| is its conjugate transpose (a row vector with every number conjugated).
  • The inner product ⟨φ|ψ⟩ is a single number. |0⟩ and |1⟩ are orthonormal: ⟨0|0⟩ = ⟨1|1⟩ = 1 and ⟨0|1⟩ = 0.

🌍 Real life: A light switch is a bit. A spinning coin is an analogy for a qubit. Be careful: a real spinning coin is secretly heads or tails, but a qubit is not hiding a value. Use the coin only for intuition.

2. Superposition, Normalization and the Born Rule

  • Superposition: |ψ⟩ = α|0⟩ + β|1⟩ with both α and β non-zero. Example: |+⟩ = (|0⟩ + |1⟩)/√2 and |−⟩ = (|0⟩ − |1⟩)/√2.
  • Born rule: P(0) = |α|² and P(1) = |β|². Probability is the squared magnitude of the amplitude, not the amplitude itself.
  • Normalization: probabilities must add up to 1, so |α|² + |β|² = 1. If not, divide both amplitudes by N = √(|α|² + |β|²).

🌍 Real life: A recipe adds up to 5 cups but you need exactly 1 cup, so you scale every ingredient by 1/5. Normalizing a state is the same idea. Also, 3 votes and 4 votes become 9/25 and 16/25 only after dividing by 5 (the 3-4-5 triangle).

3. Bloch Sphere, Global and Relative Phase

  • Every pure qubit state can be written |ψ⟩ = cos(θ/2)|0⟩ + eiφ sin(θ/2)|1⟩ and drawn as a point on a sphere: r = (sinθ cosφ, sinθ sinφ, cosθ).
  • North pole = |0⟩, south pole = |1⟩. The equator holds equal superpositions: |+⟩ (φ = 0), |+i⟩ (φ = 90°), |−⟩ (180°), |−i⟩ (270°).
  • Global phase: eiγ|ψ⟩ is the same physical state. Probabilities and the Bloch point do not change.
  • Relative phase φ: the phase between the |0⟩ and |1⟩ parts. It is physical: it moves the point around the equator and changes results in X and Y measurements.
  • Opposite points on the sphere are orthogonal states (180° on the sphere is 90° in Hilbert space).

🌍 Real life: Think of a globe. Latitude (θ) is how the probability is split between |0⟩ and |1⟩. Longitude (φ) is the relative phase. Global phase is like moving the whole clock by one hour: all time differences stay the same. Relative phase is like one dancer being a quarter-beat ahead of another.

4. Projective Measurement and Collapse

  • Measuring in the Z basis uses projectors P₀ = |0⟩⟨0| and P₁ = |1⟩⟨1|.
  • Probability of outcome m: p(m) = ⟨ψ|Pm|ψ⟩.
  • After the measurement the state collapses to Pm|ψ⟩ / √p(m). Measuring again in the same basis repeats the result.
  • X basis: |±⟩ = (|0⟩ ± |1⟩)/√2. Y basis: |±i⟩ = (|0⟩ ± i|1⟩)/√2. Each basis is a pair of opposite points on the sphere.
  • One measurement gives only one random bit. Probabilities show up only over many identically prepared qubits.

🌍 Real life: Polarized sunglasses. A vertical filter (Z basis) lets some photons through and makes them vertical. A second vertical filter passes them all (repeatable). A diagonal filter (X basis) then passes only half, because the old vertical information is lost.

5. Expectation Values and ⟨Z⟩

  • The expectation value is the average result over many measurements: ⟨A⟩ = ⟨ψ|A|ψ⟩.
  • Z = [[1, 0], [0, −1]] gives eigenvalue +1 for |0⟩ and −1 for |1⟩, so ⟨Z⟩ = P(0) − P(1) = |α|² − |β|² = cosθ.
  • Similarly ⟨X⟩ = sinθ cosφ and ⟨Y⟩ = sinθ sinφ. These are exactly the x, y and z coordinates of the Bloch vector, and each lies between −1 and +1.

🌍 Real life: A game pays ₹1 if the result is 0 and costs ₹1 if it is 1. Your average winning per round after many rounds is ⟨Z⟩. If P(0) = 85% and P(1) = 15%, you win ₹0.70 per round on average.

6. Numericals (Solved Step by Step)

Tap a question to see the solution. Use the buttons to see the answer on the sphere.

N1. Normalize |ψ⟩ = 3|0⟩ + 4i|1⟩ and find P(0), P(1).

Norm² = |3|² + |4i|² = 9 + 16 = 25, so N = 1/5.
|ψ⟩ = (3/5)|0⟩ + (4i/5)|1⟩.
P(0) = 9/25 = 36%, P(1) = 16/25 = 64%. Check: 36% + 64% = 100%.

🌍 Votes 3 and 4 turned into shares of 5.

N2. For |ψ⟩ = (1/√3)|0⟩ + √(2/3)|1⟩ find the probabilities and ⟨Z⟩.

Check: 1/3 + 2/3 = 1 ✓ (already normalized).
P(0) = 1/3 ≈ 33.3%, P(1) = 2/3 ≈ 66.7%.
⟨Z⟩ = P(0) − P(1) = 1/3 − 2/3 = −1/3.
cos(θ/2) = 1/√3 gives θ ≈ 109.47°, φ = 0.

🌍 In the ₹1 game you lose about ₹0.33 per round.

N3. Find the Bloch vector of cos(π/8)|0⟩ + sin(π/8)|1⟩.

θ/2 = π/8, so θ = π/4 = 45°, and φ = 0 (amplitudes are real).
r = (sin45°, 0, cos45°) = (0.707, 0, 0.707).
P(0) = cos²(22.5°) ≈ 85.4%, P(1) ≈ 14.6%, ⟨Z⟩ = 0.707.

🌍 A compass needle halfway between north (|0⟩) and the east direction (|+⟩).

N4. Compare |+⟩ and |−⟩. Are they different?

|±⟩ = (|0⟩ ± |1⟩)/√2. In the Z basis both give P(0) = P(1) = 1/2.
Bloch vectors: |+⟩ = (1, 0, 0) and |−⟩ = (−1, 0, 0). They differ only by relative phase (φ = 0 vs 180°).
In the X basis: |+⟩ gives + with 100%, |−⟩ gives − with 100%. So they are perfectly distinguishable, but not by a Z measurement.

🌍 Noise-cancelling headphones: a sound wave and its upside-down copy have the same loudness but cancel each other.

N5. Where is (|0⟩ + i|1⟩)/√2 on the sphere?

|α| = |β| = 1/√2, so θ = 90° (equator). The relative phase is arg(i) = 90°, so φ = 90°.
r = (0, 1, 0), P(0) = P(1) = 50%, ⟨Y⟩ = +1. A Y-basis measurement gives |+i⟩ every time.

🌍 On the globe it is the point 90° east of |+⟩ on the equator. Same latitude, different longitude.
