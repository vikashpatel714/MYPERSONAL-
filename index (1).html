1. Classical bit vs Qubit

Aapke phone/laptop me har cheez bits se bani hai. Ek bit sirf 0 ya 1 ho sakta hai, jaise light ka switch: ya ON ya OFF. Ek qubit (quantum bit) bhi measure karne par 0 ya 1 hi dikhata hai, lekin measure karne se pehle woh dono ka mixture (superposition) ho sakta hai.

Real-life example 1: Ghoomta hua sikka (spinning coin)

?

Table par ghoomta sikka na sirf Heads hai na sirf Tails, woh "dono ka mix" jaisa hai. Jaise hi aap use haath se rokte hain (measure), woh Heads ya Tails ban jata hai. Niche click karke dekhein.

Real-life example 2: Switch vs Dimmer

Classical bit = normal switch (sirf ON/OFF). Qubit = dimmer jaisa, jo 0% se 100% tak kisi bhi "mix" me ho sakta hai. Farak: qubit ko dekhte hi (measure) woh sirf ON ya OFF milta hai.

Real-life example 3: Polarized sunglasses

Ek photon ka polarization qubit ki tarah hai. Filter ke angle θ par photon pass hone ki probability cos²θ hoti hai, bilkul Born rule jaisa (neeche padhein).

2. Qubit ki state (Dirac notation)

Do basic states hain: |0⟩ ("ket zero") aur |1⟩ ("ket one"). Vector form me:

|0⟩ = [1, 0]ᵀ    |1⟩ = [0, 1]ᵀ

Koi bhi qubit in dono ka superposition ho sakta hai:

|ψ⟩ = α|0⟩ + β|1⟩    jahan   |α|² + |β|² = 1
  • α, β ko amplitudes kehte hain (complex numbers ho sakte hain).
  • |α|² = |0⟩ milne ki probability, |β|² = |1⟩ milne ki probability.
  • Normalization: total probability hamesha 1 (100%) honi chahiye.
Yaad rakhein: Amplitude probability nahi hai. Probability = amplitude ka modulus squared. Amplitude negative ya complex ho sakta hai, probability kabhi negative nahi.

Bloch sphere

Ek qubit ki state ko ek gole (sphere) par ek point/arrow se dikhate hain. North pole = |0⟩, South pole = |1⟩. Equator par 50-50 superposition wali states hain.

|ψ⟩ = cos(θ/2)|0⟩ + eiφ sin(θ/2)|1⟩

3. Live Simulation: Bloch sphere aur gates

Sphere ko mouse/ungli se ghumayein (drag). Gates lagayein aur dekhein arrow kaise ghoomta hai aur amplitudes kaise badalte hain.

Gates lagayein

Gates ka matlab

  • X gate: |0⟩↔|1⟩ (classical NOT jaisa). North pole se South pole.
  • H gate: |0⟩ → (|0⟩+|1⟩)/√2. Yahi superposition banane ka sabse common tareeka hai.
  • Z gate: |1⟩ ka sign ulta (β → −β). Probability nahi badalti, sirf phase.
  • S gate: |1⟩ ka phase i se multiply (90° ghumav equator par).
Experiment: Reset karein → H dabayein (50-50) → dubara H dabayein. Wapas |0⟩ aa gaya! Yeh interference hai, quantum computing ki asli taqat.

4. Measurement aur Born rule

P(0) = |α|²    P(1) = |β|²

Measure karte hi state collapse ho jati hai: agar result 0 aaya to state ab pakka |0⟩ hai, aur dobara measure karne par hamesha 0 hi milega. Superposition wapas nahi milta.

Measurement simulator (upar wali state use hoti hai)

Abhi koi measurement nahi hua.

Har shot me qubit fresh prepare hota hai, isliye shots measure ki tarah collapse nahi karte. Real quantum computer me bhi aise hi "shots" chalte hain.

Dhyan: |+⟩ aur |−⟩ dono ki measurement probabilities 50-50 hoti hain, lekin phase alag hai. Phase direct measurement me nahi dikhta, par H lagakar dikh jata hai.

5. Worked examples (numericals)

Example 1: Normalize karo |ψ⟩ = 3|0⟩ + 4|1⟩

Step 1: Norm nikalo: √(3²+4²) = √25 = 5.
Step 2: Sabko 5 se divide: |ψ⟩ = (3/5)|0⟩ + (4/5)|1⟩.
Step 3: P(0) = 9/25 = 36%, P(1) = 16/25 = 64%. Sum = 100%. ✓

Example 2: Equal superposition |+⟩ = (|0⟩+|1⟩)/√2

α = β = 1/√2 ≈ 0.707.
P(0) = (1/√2)² = 1/2 = 50%, P(1) = 50%. Yeh "perfect quantum coin flip" hai.

Example 3: Agar α = 1/2 ho to β kya hoga?

|α|² = 1/4. Normalization se |β|² = 1 − 1/4 = 3/4, to |β| = √3/2 ≈ 0.866.
P(0) = 25%, P(1) = 75%.

Example 4: H gate |0⟩ par lagao (matrix se)

H = (1/√2) [[1, 1],[1, −1]], |0⟩ = [1, 0]ᵀ.
H|0⟩ = (1/√2)[1·1 + 1·0, 1·1 − 1·0]ᵀ = (1/√2)[1, 1]ᵀ = |+⟩.
Ab H|+⟩ = (1/2)[1+1, 1−1]ᵀ = [1, 0]ᵀ = |0⟩. Do baar H = identity.

Example 5: Measure karne ke baad dobara measure

Qubit (3/5)|0⟩ + (4/5)|1⟩ ko measure kiya, result 1 aaya. Ab state = |1⟩.
Dobara measure: P(1) = 1 = 100%. Collapse ke baad result repeat hota hai.

Example 6: 1000 shots me kitne 0 aayenge? (P(0) = 0.36)

Expected zeros = 1000 × 0.36 = 360.
Spread (standard deviation) = √(1000 × 0.36 × 0.64) ≈ 15.2. Yaani result aksar 345 se 375 ke beech aayega. Upar simulator me khud check karein.

Example 7: Polarized sunglasses (real life)

Photon filter se 30° ke angle par hai. P(pass) = cos²30° = (√3/2)² = 3/4 = 75%. Yeh Example 3 wali hi state hai (α=1/2 wali state ka mirror).

Khud try karein (practice)

Q1. |ψ⟩ = (1/√3)|0⟩ + √(2/3)|1⟩ me P(0) aur P(1)?

P(0) = 1/3 ≈ 33.3%, P(1) = 2/3 ≈ 66.7%.

Q2. |ψ⟩ = 5|0⟩ + 12|1⟩ ko normalize karo.

Norm = √(25+144) = 13. State = (5/13)|0⟩ + (12/13)|1⟩. P(0) = 25/169 ≈ 14.8%.

Q3. X gate |1⟩ par lagane se kya milta hai?

X|1⟩ = |0⟩. Matrix: [[0,1],[1,0]]·[0,1]ᵀ = [1,0]ᵀ.

6. Real-life me kahan kaam aata hai?

Dawai khoj (drug discovery)

Molecules khud quantum rules follow karte hain, isliye qubits unhe simulate karne me natural fit hain.

Cryptography

Quantum key distribution me koi chhupke measure kare to state collapse hoti hai aur tamper pakda jata hai.

Optimization

Delivery routes, flight schedules jaise problems me superposition bahut saare options ek saath explore karne me madad karta hai.

Search

Grover's algorithm unsorted data me search karne ko classical se tez bana deta hai.

7. Quick summary (revision)

  • Qubit state: |ψ⟩ = α|0⟩ + β|1⟩, |α|² + |β|² = 1.
  • Superposition = 0 aur 1 ka combination, measure hone se pehle.
  • Born rule: P(0) = |α|², P(1) = |β|².
  • Measurement state ko collapse kar deta hai; dobara measure karne par same result.
  • Gates X, H, Z, S Bloch sphere par rotations hain.
  • Bloch sphere: North = |0⟩, South = |1⟩, equator = equal superposition.
