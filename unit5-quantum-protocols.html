No-Cloning Theorem

You cannot copy an unknown quantum state.

Statement

There is no unitary operator U that can copy an arbitrary unknown state: U(|ψ⟩⊗|0⟩) = |ψ⟩⊗|ψ⟩ for every |ψ⟩. This is why quantum information cannot be duplicated like classical bits.

Proof (by contradiction)

Suppose such a U exists. Take two states and their equal superposition |χ⟩ = (|ψ⟩+|φ⟩)/√2.
By linearity: U(|χ⟩|0⟩) = (U(|ψ⟩|0⟩)+U(|φ⟩|0⟩))/√2 = (|ψψ⟩+|φφ⟩)/√2
But cloning |χ⟩ directly should give: |χ⟩|χ⟩ = (|ψψ⟩+|ψφ⟩+|φψ⟩+|φφ⟩)/2
These two results disagree (the cross terms |ψφ⟩, |φψ⟩ are missing) unless |ψ⟩=|φ⟩. Contradiction → no universal cloning machine can exist.

Why it matters

No-cloning is why quantum cryptography (BB84 below) is secure: an eavesdropper cannot silently copy a qubit and send the original on untouched — she must measure it, and measurement disturbs it.

Quantum Teleportation

Moving a quantum state using entanglement + 2 classical bits.

What it is NOT

No matter, no energy, and no information moves faster than light. The unknown qubit's state disappears from Alice and reappears on Bob's qubit — but only after Bob receives 2 ordinary classical bits, which travel at or below light speed.

Protocol

  1. Alice and Bob pre-share a Bell pair (qubits 2 & 3).
  2. Alice has the unknown state |ψ⟩ on qubit 1.
  3. Alice applies CNOT(1→2), then H on qubit 1.
  4. Alice measures qubits 1 and 2, gets classical bits (m1,m2).
  5. Alice sends m1,m2 to Bob over a classical channel.
  6. Bob applies X if m2=1, then Z if m1=1 → his qubit becomes exactly |ψ⟩.

Superdense Coding

Sending 2 classical bits using only 1 qubit.

Protocol

  1. Alice and Bob pre-share a Bell pair.
  2. To send bits (b1,b2), Alice applies a gate to her qubit only:
00→I   01→X   10→Z   11→XZ
  1. Alice sends her single qubit to Bob.
  2. Bob now holds both qubits. He applies CNOT then H, and measures both — recovering exactly (b1,b2).

Why it works

The 4 possible gates map the shared Bell pair to the 4 orthogonal Bell states. Since the Bell basis is a valid measurement basis, Bob can perfectly distinguish all 4 — effectively doubling the classical capacity of one transmitted qubit, at the cost of pre-sharing entanglement.

Entanglement Swapping

Entangling two particles that have never interacted.

Alice shares a Bell pair with particle A2 (A1–A2), and Carol shares a Bell pair with particle C1 (C1–C2). Nobody has let A2 and C1 interact. If someone performs a Bell-basis measurement jointly on A2 and C1, the result is that A1 and C2 instantly become entangled with each other — even though they never touched. This is the core trick behind quantum repeaters, which extend entanglement over long distances by swapping across a chain of shorter links.

Quantum Key Distribution: BB84 & E91

Using quantum mechanics to detect eavesdroppers.

BB84 (Bennett & Brassard, 1984)

  1. Alice sends each qubit encoded in a randomly chosen basis: rectilinear (+: |0⟩/|1⟩) or diagonal (×: |+⟩/|−⟩).
  2. Bob measures each qubit in his own randomly chosen basis.
  3. Alice and Bob publicly announce (not the bit, only) which basis they used for each qubit.
  4. They keep only the bits where their bases matched → the sifted key.
  5. They compare a small public sample of the sifted key to estimate the error rate (QBER). High error ⇒ eavesdropper present ⇒ discard the key.

Why eavesdropping is caught

By no-cloning, Eve cannot copy a qubit. If she measures it to learn the bit, she must guess a basis — when she guesses wrong (50% of the time), she disturbs the qubit, so even when Bob later uses the same basis as Alice, he sometimes gets the wrong bit. This introduces a detectable error rate of about 25% on the sifted key when Eve intercepts every qubit.

E91 (Ekert, 1991) — intro

Uses entangled pairs instead of single prepared qubits. Alice and Bob each measure their half in randomly chosen angles and later check the CHSH value on a subset of results. If |S| is close to 2√2, there is no eavesdropper; if it drops toward 2, someone has been measuring the particles in transit, destroying the entanglement.

Numericals

Worked examples.

1. Teleportation correction table

Bob's qubit after Alice's Bell measurement, before correction, is X^(m2) Z^(m1) |ψ⟩. The correction undoing this is:
m1 m2Correction
00I (do nothing)
01Apply X
10Apply Z
11Apply X then Z

2. BB84 key rate & error detection

With N=1000 qubits sent and random bases on both sides, Alice and Bob's bases match on average 50% of the time → sifted key length ≈ 500 bits.
If Eve intercepts every qubit: she guesses the right basis 50% of the time (no disturbance), and the wrong basis 50% of the time (50% chance of flipping the bit even if Bob's basis matches Alice's). Net error on the sifted key:
QBER = 0.5 (wrong basis) × 0.5 (wrong result) = 0.25 = 25%
A QBER this high (versus ~0% with no eavesdropper, ignoring channel noise) is an unmistakable sign of interception, so Alice and Bob abort the key.

Code

Qiskit circuits and a Python BB84 simulation.

Teleportation (Qiskit)

from qiskit import QuantumCircuit

qc = QuantumCircuit(3, 3)
qc.h(1); qc.cx(1, 2)        # create Bell pair on q1,q2
qc.cx(0, 1); qc.h(0)        # Alice's Bell measurement prep
qc.measure([0,1], [0,1])    # m0, m1 are Alice's classical bits
qc.cx(1, 2)                 # apply X on q2 if m1==1
qc.cz(0, 2)                 # apply Z on q2 if m0==1
qc.measure(2, 2)            # q2 now holds the teleported state

Superdense coding (Qiskit)

from qiskit import QuantumCircuit

qc = QuantumCircuit(2, 2)
qc.h(0); qc.cx(0, 1)        # shared Bell pair

bits = "11"                 # bits Alice wants to send
if bits[1] == '1': qc.x(0)
if bits[0] == '1': qc.z(0)

qc.cx(0, 1); qc.h(0)        # Bob decodes
qc.measure([0,1], [0,1])    # recovers "11"

BB84 with an eavesdropper (plain Python)

import random

N = 1000
a_bits  = [random.randint(0,1) for _ in range(N)]
a_bases = [random.choice('+x') for _ in range(N)]
b_bases = [random.choice('+x') for _ in range(N)]
EVE = True

received = []
for i in range(N):
    bit, basis = a_bits[i], a_bases[i]
    if EVE:
        e_basis = random.choice('+x')
        if e_basis != basis:
            bit = random.randint(0,1)   # Eve disturbs it
        basis = e_basis                 # Eve resends in her basis
    if b_bases[i] != basis:
        bit = random.randint(0,1)       # Bob's own basis mismatch
    received.append(bit)

sifted_a = [a_bits[i]  for i in range(N) if a_bases[i]==b_bases[i]]
sifted_b = [received[i] for i in range(N) if a_bases[i]==b_bases[i]]
errors = sum(x!=y for x,y in zip(sifted_a, sifted_b))
print("Sifted key length:", len(sifted_a))
print("QBER:", errors/len(sifted_a))   # ~0.25 if EVE else ~0

Real-life Example: A Secret Message No One Can Eavesdrop On

Why BB84 can prove someone was listening.

The picture

Imagine mailing a message written in invisible ink that only reveals itself correctly under one of two special lamps — and the ink permanently changes if viewed under the wrong lamp, destroying the original message. Any mail carrier who peeks without knowing the right lamp has a 50% chance of ruining it. If the receiver checks a few spot letters and finds them scrambled, they know someone opened the envelope.

The limitation

Unlike invisible ink, which is a classical trick someone could in principle photograph instead of damage, a quantum qubit genuinely cannot be copied first and inspected later (no-cloning theorem). The disturbance is not a design choice to patch — it is a law of physics. That is what makes BB84 provably secure rather than just "hard to crack."
