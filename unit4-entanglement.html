Entangled vs Separable States

Can the whole be written as a product of its parts?

Separable (product) state

A two-qubit state is separable if it can be written as a tensor product of two single-qubit states:
|ψ⟩ = |a⟩ ⊗ |b⟩
Each qubit has its own independent description. Measuring one tells you nothing new about the other beyond what you already knew.

Entangled state

A state is entangled if no such factorisation exists — the two qubits must be described together. Example: (|00⟩+|11⟩)/√2. Measuring the first qubit instantly fixes the outcome of the second, even though neither qubit "contains" that outcome on its own.

How to tell them apart

  1. Try to factor the amplitudes as (α|0⟩+β|1⟩)⊗(γ|0⟩+δ|1⟩).
  2. Compare the four resulting coefficients to the actual state.
  3. If no α,β,γ,δ satisfy all four equations → entangled.
  4. Formally: compute the Schmidt rank (below). Rank 1 = separable, rank > 1 = entangled.

Bell States & the Bell Basis

The four maximally-entangled two-qubit states.

|Φ⁺⟩ = (|00⟩+|11⟩)/√2   |Φ⁻⟩ = (|00⟩−|11⟩)/√2
|Ψ⁺⟩ = (|01⟩+|10⟩)/√2   |Ψ⁻⟩ = (|01⟩−|10⟩)/√2

Properties

These four states are orthonormal and together form a complete basis for the 2-qubit space — the Bell basis. Each is maximally entangled: measuring either qubit gives a perfectly random result, but the two results are perfectly correlated (or anti-correlated).

How to build |Φ⁺⟩

  1. Start with |00⟩.
  2. Apply a Hadamard (H) to qubit 1 → (|00⟩+|10⟩)/√2.
  3. Apply CNOT (control = qubit 1, target = qubit 2) → (|00⟩+|11⟩)/√2.
This H + CNOT pair is the standard "Bell state circuit".

GHZ and W States

Entanglement across three (or more) qubits.

GHZ state

|GHZ⟩ = (|000⟩+|111⟩)/√2
All three qubits are either all 0 or all 1. Fragile: if you lose or measure just one qubit, the remaining two collapse into a classical mixture — all entanglement between them is destroyed.

W state

|W⟩ = (|001⟩+|010⟩+|100⟩)/√3
Exactly one qubit is 1 at a time. Robust: if you lose one qubit, the remaining two are still entangled (a smaller W-like state survives). This makes W states useful when qubit loss is likely.

EPR Paradox & Hidden Variables

Einstein, Podolsky, Rosen (1935): is quantum mechanics incomplete?

The argument

EPR considered two entangled particles sent far apart. Measuring one instantly determines the state of the other. EPR argued that since no signal could travel that fast, the outcome must have been pre-decided ("real") before measurement — meaning quantum mechanics is missing some hidden variable that already fixes the result.

The resolution

Bell showed in 1964 that this idea is testable: if hidden variables exist, measurement correlations must obey an inequality. Experiments (Aspect, 1982, and later loophole-free tests) show the inequality is violated, ruling out local hidden variables. Nature really is non-local in this statistical sense — yet, as shown below, this still can't be used to send a message.

Bell / CHSH Inequality

Classical limit: 2. Quantum limit: 2√2 ≈ 2.828 (Tsirelson's bound).

Setup

Alice measures her qubit at angle a or a′; Bob measures his at angle b or b′. Each measurement gives ±1. Define the correlation E(a,b) = ⟨cos(a−b)⟩. For the singlet/Bell state, quantum mechanics predicts exactly:
E(a,b) = −cos(a − b)

CHSH quantity

S = E(a,b) − E(a,b′) + E(a′,b) + E(a′,b′)
Local hidden-variable theories require |S| ≤ 2. Quantum mechanics allows up to |S| = 2√2, achieved at a=0°, a′=90°, b=45°, b′=135° (each pair of angles 45° apart).

Schmidt Decomposition (intro)

Every pure bipartite state has a clean canonical form.

Any pure state of two subsystems can always be written as
|ψ⟩ = Σᵢ λᵢ |uᵢ⟩_A |vᵢ⟩_B
where {|uᵢ⟩} and {|vᵢ⟩} are each orthonormal, λᵢ ≥ 0, and Σλᵢ² = 1. The number of non-zero λᵢ is the Schmidt rank.
  • Rank = 1 → separable (e.g. |00⟩: λ₁=1).
  • Rank ≥ 2 → entangled (e.g. Bell state: λ₁=λ₂=1/√2).
This is the rigorous version of the "try to factor it" test from Section 1.

Entanglement Entropy (intro)

A number that measures "how entangled".

Take the reduced density matrix of subsystem A (trace out B). Its eigenvalues are exactly the λᵢ² from the Schmidt decomposition. The von Neumann entropy
S(ρ_A) = −Σᵢ λᵢ² log₂(λᵢ²)
is the entanglement entropy.
  • Separable state: one λᵢ²=1, rest 0 → S = 0 (no entanglement).
  • Bell state: λ₁²=λ₂²=1/2 → S = −2×(1/2)log₂(1/2) = 1 bit — the maximum possible for a qubit pair.

No-Communication Theorem

Entanglement cannot send a message faster than light.

Even though measuring Alice's qubit instantly fixes the correlation with Bob's qubit, Bob's own measurement statistics (the reduced density matrix on his side) never change based on what Alice chooses to measure or whether she measures at all. Mathematically, any local operation Alice performs commutes with Bob's reduced state. So:
  • Bob sees pure randomness either way — he cannot tell if Alice has measured.
  • The correlation is only visible after Alice and Bob compare notes over a classical channel (phone, internet — limited by light speed).
  • This is why entanglement does not violate relativity.

Numericals

Worked examples, step by step.

1. Build the Bell state

Start: |00⟩ = (1,0,0,0)ᵀ.
H on qubit 1: (1/√2)(|00⟩+|10⟩).
CNOT (q1→q2): (1/√2)(|00⟩+|11⟩) = |Φ⁺⟩. ✅

2. CHSH value = 2√2

Use a=0°, a′=90°, b=45°, b′=135°, with E(x,y)=−cos(x−y):
E(a,b)=−cos(−45°)=−0.707
E(a,b′)=−cos(−135°)=+0.707
E(a′,b)=−cos(45°)=−0.707
E(a′,b′)=−cos(−45°)=−0.707
S = E(a,b)−E(a,b′)+E(a′,b)+E(a′,b′)
S = −0.707−0.707−0.707−0.707 = −2.828
|S| = 2√2 ≈ 2.828 — exactly the Tsirelson bound, and well above the classical limit of 2. Try it live in the simulator above (click "Jump to quantum-optimal angles").

3. Show (|00⟩+|11⟩)/√2 is NOT a product state

Assume |ψ⟩=(α|0⟩+β|1⟩)⊗(γ|0⟩+δ|1⟩) = αγ|00⟩+αδ|01⟩+βγ|10⟩+βδ|11⟩.
Match to (1/√2)|00⟩ + 0|01⟩ + 0|10⟩ + (1/√2)|11⟩:
αδ=0 and βγ=0, but αγ=1/√2≠0 and βδ=1/√2≠0.
αδ=0 ⟹ α=0 or δ=0. If α=0, then αγ=0 ≠1/√2 — contradiction. If δ=0, then βδ=0≠1/√2 — contradiction. No valid α,β,γ,δ exist, so the state cannot be factored — it is entangled. ✅

Code

Qiskit-style Bell circuit, and a CHSH correlation simulator.

Bell state circuit (Qiskit)

from qiskit import QuantumCircuit

qc = QuantumCircuit(2, 2)
qc.h(0)        # superposition on qubit 0
qc.cx(0, 1)    # CNOT: entangle qubit 0 and 1
qc.measure([0,1],[0,1])
# Result: ~50% '00', ~50% '11', never '01' or '10'

CHSH correlation (Python, no hardware needed)

import math, random

def E(a, b, trials=20000):
    """Quantum prediction for the singlet state: E = -cos(a-b)"""
    return -math.cos(math.radians(a - b))

a, a2, b, b2 = 0, 90, 45, 135
S = E(a,b) - E(a,b2) + E(a2,b) + E(a2,b2)
print("CHSH S =", abs(S))   # 2.828... = 2*sqrt(2)

Real-life Example: The Glove Analogy

A useful picture — and exactly where it breaks down.

The analogy

Put a left glove and a right glove into two identical boxes, mail one to Alice and one to Bob without telling either which is inside. The moment Alice opens her box and sees "left", she instantly knows Bob has "right" — no signal needed, because the correlation was fixed the moment the gloves were packed.

Why it is a good first picture

It correctly shows that correlation ≠ communication: Alice learns about Bob's glove without any signal travelling between them. This mirrors the no-communication theorem.

Where it breaks down

The glove outcome was fixed in advance — a classical hidden variable (which glove went in which box). Bell's theorem proves entangled qubits are not like this: there is no fixed "glove" waiting to be revealed. The CHSH simulator above shows quantum correlations exceeding 2 — something gloves (or any pre-set classical property) can never do, since gloves always give |S| ≤ 2. The entanglement is created and remains genuinely undetermined until measured.
